# BMP seed corpus

Valid, well-formed BMP files used as fuzzing seeds for `bmp_parser`.
Generated by `gen_seeds.py` (pure `struct`, reproducible anywhere —
no imaging library needed):

```sh
python3 gen_seeds.py .
```

| File | Shape | Why it is here |
|---|---|---|
| `rgb24_8x8.bmp` | 24bpp, 8x8 | Smallest plain RGB seed |
| `rgb24_16x16.bmp` | 24bpp, 16x16 | More pixel data to mutate/splice |
| `rgb24_5x7.bmp` | 24bpp, 5x7 | Row padding (stride 16 > 15 data bytes) |
| `rgb24_topdown_8x8.bmp` | 24bpp, height = -8 | Top-down row order path |
| `argb32_4x4.bmp` | 32bpp, 4x4 | 4 bytes-per-pixel path |
| `pal8_16x16.bmp` | 8bpp, 256-entry palette | Full palette; file is 1334 bytes |
| `pal8_8x8_16col.bmp` | 8bpp, 16-entry palette | `biClrUsed` smaller than 256 |

Every seed must parse cleanly under a sanitizer build — a crashing
seed invalidates the calibration baseline.
